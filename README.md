# DomZaddy.com

The website of DomZaddy Games, an indie game studio: Keeps & Conquerors, Under the Kingdom, the videos, the studio and the
book She Sat Alone (by Colten Rose, the author name of DomZaddy). Static HTML, CSS and JavaScript on GitHub Pages.

- `index.html`, `games.html`, `videos.html`, `studio.html`, `books.html`; shared look in `site.css`, shared nav, footer and
  video pop-up in `chrome.js`.
- `media/videos.json` is refreshed every day by `.github/workflows/refresh-videos.yml` from the YouTube channel feed.
- The forms post to Formspree.
